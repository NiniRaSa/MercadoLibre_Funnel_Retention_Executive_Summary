# MercadoLibre: User Conversion Funnel & Cohort Retention Analysis (SQL)

## Project Overview
Acting as a Product & Growth Data Analyst for **MercadoLibre**, I explored relational user-event schemas and queried behavioral data using **SQL** to build an end-to-end conversion funnel and cohort retention model. The objective was to deliver an actionable executive summary to Product and Growth Leadership to optimize user onboarding, lifecycle notifications, and long-term retention.

## Technical Execution & Analytical Methodology
* **Schema Exploration & User Flow Mapping (SQL):** Navigated event-tracking and user tables to map sequential behavioral milestones across the customer lifecycle.
* **Conversion Funnel Modeling (SQL):** Engineered multi-stage funnel queries using conditional aggregations, `JOINs`, and Common Table Expressions (**CTEs**) to calculate stage-to-stage conversion rates and pinpoint critical user drop-off bottlenecks.
* **Cohort Retention Analysis (SQL):** Segmented users by acquisition cohort and computed time-based retention matrices in SQL (`DATE_TRUNC` / date intervals, `COUNT(DISTINCT)`) to isolate top-performing cohorts and diagnose early churn drivers.
* **Executive Storytelling (C→F→I Framework):** Synthesized SQL outputs and visual dashboards into a one-page executive brief structured under the **Context → Finding → Implication (C→F→I)** method to propose concrete product interventions (onboarding optimization, targeted push notifications, and loyalty rewards).

## Tools & Technical Skills
* **SQL (Relational Databases):** Conversion Funnel Queries, Cohort Retention Matrices, CTEs, Multi-Table `JOINs`, Date/Time Functions, Behavioral Segmentation.
* **Product & Business Intelligence:** Funnel & Churn Diagnostics, Executive One-Pager Design, Data Visualization, C→F→I Strategic Storytelling.
